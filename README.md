# Вкусно едем — Telegram Mini App

Мини-приложение доставки (пицца, суши, шаурма, бургеры) для сообщества
[vk.ru/vkusnoedem](https://vk.ru/vkusnoedem), Кунашак.

Меню, цены и баннер взяты с открытой страницы сообщества. Фото блюд для части
позиций VK не отдаёт без авторизации, поэтому такие карточки используют
Sфирменные цветные иконки вместо фото — при желании их легко заменить на
реальные снимки (см. ниже).

## Стек

Обычные HTML/CSS/JS без сборки — открывается как статический сайт.
Подключён [Telegram WebApp SDK](https://core.telegram.org/bots/webapps) для
работы внутри Telegram (кнопка заказа, цвета шапки, отправка заказа боту).

## Как подключить к Telegram

1. Разверните сайт (например, на Vercel — уже сделано, ссылка у вас есть).
2. В [@BotFather](https://t.me/BotFather) создайте бота (`/newbot`), если его ещё нет.
3. Команда `/mybots` → выбрать бота → **Bot Settings → Menu Button** → указать
   URL деплоя. Либо создать кнопку через `/setmenubutton`.
4. Чтобы получать оформленные заказы, добавьте на сервере бота обработчик
   `web_app_data` — приложение отправляет `tg.sendData()` с JSON заказа
   (список позиций, количество, сумма). Сейчас это не подключено — нужен
   отдельный бэкенд/бот-скрипт, который получает это событие и, например, пересылает заказ в чат.

## Как заменить иконки на реальные фото

В `app.js` у каждого товара в массиве `PRODUCTS` есть необязательное поле
`photo` — укажите прямую ссылку на изображение, и карточка покажет фото вместо
иконки (см. пример у позиции «Пепперони»).

## Локальный запуск

Просто откройте `index.html` в браузере, либо поднимите любой статический
сервер:

```bash
npx serve .
```
