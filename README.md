# Суши Палки — Telegram Mini App

Доставка роллов, пиццы и снэков в Кунашаке. Мини-приложение для Telegram + бот на вебхуках, всё на Vercel.

**Живой адрес:** https://vkusnoedem.vercel.app

## Стек
- Фронтенд: чистые HTML/CSS/JS (без сборки), Telegram Web App SDK
- Бэкенд: Vercel Serverless Functions (`/api/*`, Node.js, без внешних зависимостей — только `fetch` к Bot API)
- Каталог: `data/items.json`
- Хостинг: Vercel, репозиторий подключён к GitHub (автодеплой на пуш в `main`)

## Структура
```
index.html        — разметка
style.css          — стили
app.js             — каталог, корзина, форма заказа, MainButton
data/items.json    — товары (те же данные, что и в app.js)
api/order.js       — принимает заказ, шлёт уведомления в Telegram
api/bot.js         — вебхук бота (/start → кнопка открытия приложения)
api/set-webhook.js — разовая регистрация вебхука и кнопки меню
```

## Настройка бота (сделать один раз)

1. **Получить токен.** В `@BotFather` → `/newbot` (или используйте существующего бота) → скопировать токен вида `123456:ABC-DEF...`.

2. **Задать переменные окружения в Vercel** (Project Settings → Environment Variables → Production):
   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `ADMIN_CHAT_ID` | ваш Telegram chat ID (куда будут падать уведомления о заказах) |
   | `APP_URL` | `https://vkusnoedem.vercel.app` |

   Узнать свой `chat_id`: напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш ID.

   После добавления переменных нажмите **Redeploy** в Vercel, чтобы функции их подхватили.

3. **Зарегистировать вебхук.** Откройте в браузере один раз:
   ```
   https://vkusnoedem.vercel.app/api/set-webhook
   ```
   Должен вернуться `{"ok":true, ...}`. Это одновременно ставит вебхук бота и кнопку «Меню» рядом с полем ввода в чате.

4. **Подключить Mini App в BotFather** (чтобы приложение открывалось не только по кнопке из `/start`, но и через cредесией бота):
   `@BotFather` → `/mybots` → выбрать бота → **Bot Settings → Menu Button** → указать `https://vkusnoedem.vercel.app`.
   Также можно включить полноценный Mini App через `/newapp`, если нужна отдельная карточка приложения.

5. Готово — напишите боту `/start`, откройте меню, оформите тестовый заказ. Чек придёт вам в личку, а полная информация о заказе — в `ADMIN_CHAT_ID`.

## Как это работает
- Пользователь открывает Mini App из бота → выбирает товары → корзина считается на клиенте (`localStorage`).
- При оформлении: `app.js` собирает форму (имя, телефон, адрес/самовывоз, комментарий) и шлёт `POST /api/order` вместе с `Telegram.WebApp.initData`.
- `api/order.js` проверяет подпись `initData` (HMAC по алгоритму Telegram), формирует чек и отправляет два сообщения через Bot API: клиенту (чек) и в `ADMIN_CHAT_ID` (полный заказ с контактами).
- `api/bot.js` обрабатывает вебхук бота: на `/start` присылает приветствие с кнопкой запуска приложения.

## Локальный запуск
Статику можно открыть напрямую (`index.html`) — приложение работает и вне Telegram (кнопки Telegram скрываются, чекаут показывает `alert`). Для локальной проверки `/api/*` понадобится Vercel CLI:
```bash
npm i -g vercel
vercel dev
```
и `.env.local` с `BOT_TOKEN` / `ADMIN_CHAT_ID` / `APP_URL=http://localhost:3000`.

## Деплой
Автоматический — любой коммит в `main` на GitHub триггерит прод-деплой на Vercel (репозиторий уже подключён).

## Про каталог и фотографии товаров
Каталог (96 товаров) собран из официального экспорта сообщества ВКонтакте «Суши Палки» (`vk.com/market-225061453`) — YML-фид формата Яндекс.Маркета (`market.vk_yml.xml`), выгруженный из настроек магазина ВК 05.09.2026. У каждого товара — название, цена, состав и прямая ссылка на фото из фида; собственных описаний/выдуманных данных нет. Веса в исходных описаниях нет ни у одной позиции, поэтому поле веса на карточках товара не используется.

Категории фида сверены вручную: 2 позиции (морс и чизкейк) в исходном фиде были без нормальной категории (числились под служебным id `30543`) — вынесены в отдельную категорию «Напитки и десерты».

Фото подключены по прямым CDN-ссылкам ВК (`vkuserphoto.ru`, подписанные URL) — не скопированы в `assets/`, ссылки стабильны и обновляются вместе с фидом при повторном экспорте.

Чтобы обновить каталог из нового экспорта: выгрузите свежий YML-фид (Сообщество → Товары → Экспорт) и попросите пересобрать `data/items.json` и `PRODUCTS` в `app.js` из него.
